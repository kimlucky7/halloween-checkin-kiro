## 4. Local storage and reliable publication

- [x] 在本地 D1/R2 等效测试环境设计迁移、操作表、版本化媒体及最小公开投影（R5/R7）（`migrations/0002`，node:sqlite 与内存 R2 替身；另在 workerd 本地模式验证）
- [ ] 实现逻辑发布/状态查询能力，明确实际 MCP 文件传输协议，不依赖远端可读取本地路径（HTTP 接口已实现；MCP/OAuth 连接器与宿主文件协议未实现、未验证）
- [x] 实现原子幂等争用、相同请求重放、键/hash 冲突拒绝；以同一操作 ID 恢复超时。先校验身份/所有权/项目和原 revision/hash，已有结果重放零新副作用；过期/撤销后需要新写入的恢复必须重新审核并获得有效批准（唯一索引 + 重放测试；单进程替身，未做生产并发压测）
- [ ] 测试提交后批准过期/撤销：正确所有者可查询/重放相同已有结果；无新媒体、记录或发布任务；新操作、错所有者/项目、同键不同 hash 均拒绝，未完成操作仅报告实际状态
- [x] 实现先媒体后数据库可见提交；未引用/未批准媒体不可公开访问（未引用/未发布媒体返回 404，已测）
- [x] 注入第二对象上传失败、数据库失败、响应丢失和并发双请求；确认无重复记录或公开半成品（对象存储失败、提交前失败、提交后响应丢失、批次回滚）
- [ ] 设计范围受限的过期临时对象清理；不永久删除历史/生产数据（未实现）

检查点：可从日志和操作查询说明“到底发布了没有”，不能靠重试碰运气。
