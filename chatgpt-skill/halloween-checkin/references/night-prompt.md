# Night prompt (halloween-night, an edit of the accepted normal day)

The only image input is the **accepted** normal-day image — never the original photo.
One edit adds a few small Halloween decorations and night lighting; the shapes, camera,
framing, size, sign lettering and magenta background stay the same, so the model does
not move or resize when the site switches between day and night. BACKDROP is defined in
day-prompt.md. Send the prompt exactly as written.

## halloween-night

Image input: the accepted normal-day image only.

> Edit this exact miniature into a Halloween night scene: add a few small decorations — a carved glowing pumpkin by the door, a string of orange lights along the shopfront, one paper bat on the wall — and relight it as night with dark blue ambient light and warm glowing windows and sign. Keep every shape, the camera, the framing, the size, the sign lettering and the magenta background exactly the same; do not redraw or widen the building. Decorations stay small, sit on the building and never cover the sign. BACKDROP

The decorations are creative additions; list each one in `differences` when submitting.

If the result moved, resized, redrew or re-lettered anything, that is a core failure:
retry once with "keep every shape and the sign identical; only add the small decorations and night lighting".
