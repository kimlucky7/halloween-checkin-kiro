# Night prompts (relight an accepted day image)

The only image input is the **accepted** day image of the same edition — never the original
photo. Night changes lighting only: same shapes, camera, framing, sign lettering and magenta
background. BACKDROP is defined in day-prompt.md. Send the prompt exactly as written.

## normal-night

Image input: the accepted normal-day image only.

> Relight this exact miniature as night: dark blue ambient light, warm glowing windows and sign. Keep every shape, the camera, the framing, the sign lettering and the magenta background exactly the same; change only the lighting on the object. BACKDROP

## halloween-night

Image input: the accepted halloween-day image only.

> Relight this exact decorated miniature as night: dark blue ambient light, glowing windows, sign, pumpkin and string lights. Keep every shape, the framing, the sign and the magenta background the same; change only the lighting. BACKDROP

If the night image moved, resized, redrew or re-lettered anything, that is a core failure:
retry once with "change only the lighting; keep every shape and the sign identical".
